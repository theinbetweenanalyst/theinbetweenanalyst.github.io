Privacy Policy

The In-Between Analyst upload tool · Last updated 12 November 2026

The In-Between Analyst uses a private upload tool to post its own videos to its own YouTube channel. Only the channel owner uses it, on their own computer. This policy explains what the tool accesses and what it does with it.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy (https://policies.google.com/privacy).

What the tool accesses

The tool asks Google for one permission, youtube.upload, which lets it upload videos to the signed-in YouTube channel. It doesn't ask for permission to read, change, or delete existing videos, comments, subscribers, or any other account data.

It uploads video files the channel owner made, along with their title, description, tags, privacy setting, and the "altered or synthetic content" label. Every upload is set to private.

How information is stored

Google sign-in tokens are stored only in the macOS Keychain on the channel owner's computer. They are not sent to any server other than Google's, and not shared with anyone.

After an upload, the tool saves the new video's ID and link in a local file so the owner can find it.

What the tool doesn't do

  • It doesn't collect information about viewers or other YouTube users.
  • It doesn't sell, share, or transfer any data to third parties.
  • It doesn't use data for advertising.

Data retention and deletion

  • Sign-in tokens are kept only while the tool is in use. They are deleted from the macOS Keychain when access is revoked or the tool is no longer used.
  • Upload records (video ID, link, and upload time) are kept on the owner's computer only, and can be deleted at any time by deleting the local record file.
  • No YouTube data is cached or stored beyond the ID and link of videos the tool itself uploaded.
  • To ask for any data to be deleted, email the contact below. Requests are handled within 7 days.

Revoking access

Access can be revoked at any time on the Google security settings page (https://myaccount.google.com/permissions). Revoking it makes the stored token stop working immediately.
